# Aplicativo de Cupcakes (PIT II)
Aluno: Bruno Franceschi Somera | RGM: 42568307
Front end: HTML, CSS e JavaScript. Back end: Python (Flask) em MVC. Banco: SQLite (schema.sql e cupcakes.db).
## Como rodar
pip install -r requirements.txt
python app.py
Acesse http://127.0.0.1:5000
## Testes
python test_app.py (atenção: recria o cupcakes.db)
## Estrutura
models/ (dados) | controllers/ (rotas e regras) | views/ (HTML) | static/ (CSS e JS)
